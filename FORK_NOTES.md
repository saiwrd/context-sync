# Fork notes

This is a fork of **[Intina47/context-sync](https://github.com/Intina47/context-sync)** (MIT), an MCP server that gives AI coding tools persistent memory. The project, code, documentation and license belong to its upstream author and contributors. Nothing here is presented as my work.

## Why I keep this fork

I follow it as a reference for how MCP servers can hold long-lived project context, which is the same problem I hit with agent-driven GTM work (client context that must survive between sessions).
